# Student Management System

## Project Overview
The Student Management System is a web-based application developed to manage student records efficiently.

## Technologies Used
- Frontend: React JS
- Backend: Node.js
- Framework: Express.js
- Database: MySQL
- API: REST API

## Main Features
1. Admin Login
2. Add Student
3. View Students
4. Edit Student
5. Delete Student
6. Search Student
7. Admin Dashboard

## Database
Database Name: student_management

Main Table: students
